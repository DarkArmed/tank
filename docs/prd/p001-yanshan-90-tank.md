状态：范围已确认，待用户分配 Task  
产品形态：浏览器端、俯视固定画面的坦克对战游戏  
对标作品：福州烟山软件《烟山90坦克》（又称 Tank 1990 / 90坦克）  
规则来源：公开玩家文档对照整理，**不使用、不内置任何 ROM 或原版素材**

已确认：

- 第一版只做核心可玩，**不做模式选择**。
- **只做 5 张地图**，连续游玩。
- 第 10 节默认规则全部采用。
- 画面 **严格 FC 像素**：内部 256×240，只做整数倍邻近放大。

## 1. 背景与目标

国内多数玩家童年接触的「坦克大战」，实际是南梦宫 FC《Battle City》（1985）的烟山改版。本项目用原创像素资源复刻其核心玩法。

第一版要回答：玩家能否在浏览器里完成「守家 + 清敌 + 吃宝」，并感受到烟山版相对原版的关键差异。

---

## 2. 用户与核心流程

### 2.1 用户

- 单人：键盘控制 1P。
- 双人：同机分键位合作，可借命。

### 2.2 核心用户流程

1. 打开游戏，进入标题。
2. 选单人或双人后开战（无模式菜单）。
3. 关卡为 13×13 地图：总部在底部中央，1P 左、2P 右出生；敌人从顶部三处进入。
4. 总部未被摧毁的前提下，消灭本关 20 辆敌方坦克。
5. 进入下一张图（共 5 张，打完第 5 张后循环回第 1 张或显示通关后回标题，第一版默认 **通关 5 张后回标题**）。
6. 生命耗尽或总部被毁则本局结束；双人可借命。

## 3. 范围

### 3.1 必须有

- 固定俯视战场、四向移动与射击。
- 地形：空地、砖、钢板、草、冰、河、总部。
- 每关 20 敌；单人场上最多 4 敌，双人最多 6 敌。
- 玩家升级、生命、计分、过关 / 失败。
- 固定采用烟山「经典」规则（对应资料中的 15–28 + 敌人可吃宝），无开关菜单：
  - 道具「枪」「船」
  - 可消草（按第 10 节等级周期）
  - 敌方可拾取道具
  - 任意分值敌人均可带装甲（层数可变）
  - 敌方刷新较快，可同时从多个出生点出现
  - 双人炮弹穿过队友，不定身
  - 双人借命
- **5 张** 13×13 可玩地图，布局需覆盖砖/钢/草/冰/河的差异，避免五张同质。
- 画面：FC 256×240 帧缓冲 + 整数倍放大；原创像素，战场 13×13、每格 16px（战场 208×208），右侧状态栏（分数、生命、剩余敌）。

### 3.2 不做

- 任何 ROM、原版/改版版权图、字体、音乐采样。
- 28 模式、TANK A–N 选关、01–14 / 15–28 切换。
- 第 6 张及以后的地图、第 0 关、调命秘技。
- 《导弹坦克 / 92坦克》。
- 关卡编辑器、联网、排行榜、账号、触控。
- 非整数缩放、滤镜、平滑放大。

### 3.3 后续（不挡第一版）

- 完整模式与地图包、帧级 AI/随机对齐、调命秘技。

## 4. 战场与基础规则

### 4.1 地图

- 战场 **13×13** 大格；砖等可破坏物按半格破坏。
- 总部底部中央，砖围；1P 总部左、2P 右；敌人左上 / 顶中 / 右上。
- **砖**：挡坦克与子弹，可逐层打掉。
- **钢板**：挡坦克与普通子弹；可打钢火力可破坏。
- **草**：可通过；草下单位难看清。
- **冰**：滑行。
- **河**：无船不可进入；子弹可通过。
- **空地**：无阻挡。
- **总部**：任意子弹打中即失败（含误伤、含清敌之后）。

### 4.2 过关与失败

- 过关：消灭 20 敌且总部仍在。
- 失败：总部被毁，或生命耗尽（双人见第 7 节）。
- 初始生命：1P / 2P 各 3。
- 每 20000 分 +1 命。

### 4.3 玩家坦克（1P 黄、2P 绿）

- 四向移动与射击。
- 火力：
  - 1：同时 1 发弹
  - 2：射速提高
  - 3：同时 2 发弹
  - 4：可打钢板；对砖更强
- 生存（已确认）：
  - 火力 ≥4：抵挡 1 次击毁，降到 3 级
  - 有船：另抵挡 1 次，先掉船
  - 枪：升 3 级且带 1 次抵挡（与纯吃 3 星不同）

### 4.4 敌方坦克

- 职能：普通、高速、快射、重甲；任意类可带 1–3 层甲；闪光/红坦克也可带甲。
- 击毁闪光坦克掉宝。
- 出生种类按关卡表随机抽取，不强制还原原作每一关序列。
- 场上上限：单人 4、双人 6。

---

## 5. 固定规则（无模式）

全程开启：船、消草（按等级表）、敌人可吃宝。标题只选人数。

---

## 6. 道具

场上同时只有最新一个道具；新红坦克出现不清除已在场道具。

### 6.1 玩家

| 道具 | 效果 |
| --- | --- |
| 星星 | 火力 +1；消草按第 10 节周期 |
| 枪 | 升 3 级 + 1 次抵挡 |
| 船 | 过河；抵挡 1 次后失去船 |
| 钢盔 | 短时间无敌 |
| 铁锹 | 总部外围先变钢板，计时结束后变回初始砖围 |
| 坦克 | +1 命 |
| 时钟 | 敌人短时间不能移动、不能射击 |
| 炸弹 | 消灭场上全部敌人（计入击毁数） |

### 6.2 敌人拾取

| 道具 | 效果 |
| --- | --- |
| 星星 | 场上全部敌人可打钢板 |
| 枪 | 该敌人可打钢板 |
| 船 | 该敌人可过河 |
| 钢盔 | 场上敌人变为 3 层装甲红坦克 |
| 坦克 | 场上敌人变为 3 层装甲；再吃则在红甲 / 非红甲间切换 |
| 铁锹 | 扒光我方总部砖墙 |
| 时钟 | 我方短时间不能移动，仍可射击 |
| 炸弹 | 炸死 1P 与 2P 当前坦克 |

消草：火力 5–6 可消草，7–9 不可，之后按「2 级可消 / 3 级不可」循环（写成等级表）。

---

## 7. 双人

- 同机键盘。1P：WASD + J 射击 + K 借命。2P：方向键 + 小键盘 1 射击 + 小键盘 2 借命。若小键盘不便，2P 射击用 `/`，借命用 `.`。
- 友军炮弹穿过队友，无伤害、不定身。
- 一方生命为 0 时按借命键，从另一方扣 1 命并复活。
- 复活有短暂无敌。

---

## 8. 画面与操作

- 逻辑分辨率 **256×240**。窗口尺寸只能是其整数倍（×2 / ×3 / ×4…），`image-rendering: pixelated`，禁止模糊。
- 战场：左上偏移后 208×208（13×16px），右侧 48×240 为 HUD（关卡、分数、生命图标、剩余敌图标）。
- 标题：游戏名、1 PLAYER、2 PLAYERS，看懂即可，不抄原版字体。
- 失败可回标题重开。
- 过关有短暂过渡即可，不强制原版统计屏。

---

## 9. 验收标准

1. 浏览器打开即可打单人。
2. 移动、射击、地形阻挡符合第 4 节。
3. 清 20 敌过关；总部中弹立即失败。
4. 5 张地图都能进入；其中至少 1 张能看到草、冰、河、钢的正确效果。
5. 船、枪、消草、敌人吃宝（炸弹/铁锹/星星）可观察到。
6. 双人可同时操作、友弹穿过、可借命。
7. 5 关能连续打完，无必现崩溃。
8. 画面为 256×240 整数倍放大；仓库无 ROM。
9. 类型检查与必要测试通过。

## 11. 非功能

- 前端 TypeScript + React + Vite；战斗主循环用 Canvas，不为组件化拆大量组件。
