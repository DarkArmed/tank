# t003 前三关地图数据

对应需求：p001

技术设计：`docs/DESIGN.md`

状态：未分配

## 目标

根据用户提供的网上参考素材，实现第一组 TANK A 第 1～3 关的半格地图数据，供当前 A～N 共用。

## 范围

- 只修改 `frontend/src/sim/maps/`。
- 提供 `stage-1.json`、`stage-2.json`、`stage-3.json`。
- 按 DESIGN 的 26×26 半格格式转录地形、总部和五个出生点。
- 为三张地图提供结构验证。
- 当前参考图中被坦克、道具或动画遮挡的位置，按周边连续地形记录为临时值，并在交付说明中列出。

## 不包含

- 第 4 关及以后地图。
- 战斗规则、地图加载器、绘制或输入。
- 提交网上截图、水印、原版素材、ROM 或录像。
- 等待或执行 t005 实机验证。

## 依赖

- p001 当前地图需求。
- `docs/DESIGN.md` 的地图格式。
- 用户已经提供的第 1～3 关网上参考素材。
- **不依赖 t005**；t005 是之后的独立准确性复核。

## 涉及模块

- `frontend/src/sim/maps/`

## 验收标准

- 恰好提交三张发布地图，ID 为 1、2、3，均可通过 DESIGN 规定的地图校验。
- 每张地图为 26×26 半格，包含单个 2×2 总部、两个玩家出生点和三个敌人出生点。
- 地形布局与当前批准的对应参考图一致。
- 三张地图可以按顺序加载；A～N 复用同一地图集合。
- 仓库中不包含参考截图或其它原作媒体。
- 不修改 t001、t002 的写入范围。

## 验证方式

1. 运行地图结构校验和 Targeted Vitest。
2. 将每张 JSON 渲染为无素材的彩色网格，与参考图逐半格对照。
3. 接入 t001 后验证三关均可加载、总部和出生点有效。
4. 用户手动确认当前参考版本后，Task 才能最终完成。
