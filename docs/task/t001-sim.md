# t001 对战逻辑

对应：p001

## 目标

实现完整第一版规则的纯逻辑层（不含像素绘制、不含五张发布用地图）。表现层只调用 `tick` 读快照。

## 范围

- 目录仅限：`frontend/src/sim/`，**不含** `frontend/src/sim/maps/`。
- 读取 t003 地图 JSON 的加载器（格式见 t003）；t003 未就绪时，测试内嵌 **1 张** 最小地图即可。
- 地形碰撞、砖半格破坏、钢/草/冰/河/总部。
- 玩家与敌人坦克、子弹、出生与场上上限、基础 AI。
- 8 种道具及敌我拾取（p001 第 6、10 节）。
- 关卡状态机、20 敌过关、5 图顺序、生命、计分、20000 加命。
- 双人输入结构、友弹穿过、借命。
- 导出：`createGame` / `tick(input)` / `getSnapshot()`，类型与 p001 第 13 节一致。

## 不包含

- 五张发布用 JSON 地图（属 t003）。
- 任何 React、Canvas、CSS、Vite 配置、`package.json`。
- 标题 UI、HUD 绘制、键位绑定。
- 模式选择。

## 依赖

无。可与 t002、t003 并行。

## 涉及模块

`frontend/src/sim/**`（排除 `maps/`）

## 验收标准

- Vitest 覆盖：地形碰撞、过关/失败、挡一枪/船/枪、消草等级表、敌人吃炸弹与铁锹、借命、友弹不伤队友。
- 用内嵌测试地图纯逻辑打完至少 1 关不崩溃；加载器能接受 t003 的 JSON schema。
- 不修改 t002、t003 负责的文件。

## 验证方式

- 在已有 Vite 工程中跑 `src/sim` 的 Vitest；若工程尚未创建，先保证测试与实现可被后续接入。
- 不启动浏览器也必须能测核心规则。
