# t005 前三关地图实机复核

对应需求：p001 第 1、3、15 节

技术设计：不适用

状态：已分配，待执行

执行人：用户

## 目标

使用目标版本实机或模拟器，独立复核第一组 TANK A 第 1～3 关地图，识别网上素材的版本错误、关卡错配和被单位遮挡的半格。

本 Task 只形成原作观察证据，不阻塞 t003，也不自动修改项目地图。

## 范围

- 登记目标版本、`01→14` 组、TANK A、模拟器或设备信息。
- 在每关地形未被破坏时采集完整战场画面。
- 对照 t003 的无素材彩色网格，逐半格记录一致、不同或无法判断。
- 特别复核总部围墙、五个出生点、单位或道具遮挡区域。
- 复核网上素材中两张不同“第3关”地图的版本归属。
- 原始截图和录像保存在仓库外；仓库只记录结论、时间点和必要哈希。

## 不包含

- 修改地图 JSON、模拟代码或 DESIGN。
- 提交 ROM、原版图片、录像、反汇编代码或其它原作素材。
- 用网上攻略或其它复刻项目代替目标版本观察。
- 阻塞 t003 的实施或当前参考版本验收。

## 依赖

- 用户可运行的目标版本。
- t003 输出的三张地图彩色网格；若 t003 尚未完成，可先采集实机画面，之后再对照。
- p001 当前地图要求。

## 涉及文档

- 记录本 Task 的版本、证据和结论。
- 若发现差异，先提出 p001 地图需求修订；用户确认后再安排地图修改。

## 证据要求

- 每关画面必须包含完整 208×208 战场和可辨认的关卡编号。
- 优先在开局单位尚未移动、地形尚未被破坏时采集；无法避免遮挡时补充同一区域的后续画面。
- 每处差异记录关卡、半格行列、当前地图值、观察值、截图文件名和时间点。
- 不能确认的半格保持“未知”，不得按网上素材或项目实现反推。

## 验收标准

- 第 1～3 关均有目标版本、模式、关卡编号和完整画面记录。
- 所有差异和遮挡半格都有明确结论或标记为无法判断。
- 第3关来源冲突得到归属结论，或明确保留为未解决。
- 仓库中没有原作图片、录像或 ROM。
- 用户明确决定是否更新 p001；未确认前不修改项目地图。

## 验证方式

1. 用户提交仓库外证据的文件名、时间点和逐关结论。
2. Agent 将 t003 网格与观察逐半格比对。
3. 用户确认保留当前地图或修订 p001。
4. 完成上述确认后才将 t005 标记为最终完成。
