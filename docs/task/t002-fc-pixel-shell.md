# t002 FC 像素壳与输入

对应：p001

## 目标

建立前端工程，按 FC 256×240 整数倍放大绘制快照，并绑定键盘。不实现战斗规则，不编写地图数据。

## 范围

- 创建 `frontend/`：Vite + React + TypeScript + Vitest 脚手架。
- **不要** 往 `frontend/src/sim/` 写规则或地图。若 t001 尚未提交，允许在 `frontend/src/app/` 内放最小 stub（固定假快照），t001 合并后改为调用真 `tick`。
- Canvas：内部 256×240，窗口整数倍缩放，邻近取样、无模糊。
- 布局：战场 208×208 + 右侧 HUD。
- 标题：1P / 2P；战斗、过关过渡、失败回标题。
- 键位按 p001 第 7 节采集，每 tick 传给逻辑。
- 原创色块/简易像素即可，不抄原版贴图；坦克用黄/绿/灰矩形可过验收。

## 不包含

- 地形规则、AI、道具效果、过关计数。
- `frontend/src/sim/` 规则代码（t001）与 `maps/` JSON（t003）。
- 后端。

## 依赖

无。可与 t001、t003 并行。对接约定见 p001 第 13 节。

## 涉及模块

`frontend/` 中除 `frontend/src/sim/` 以外的文件。

## 验收标准

- 前端可启动；画面为 256×240 的整数倍，放大无模糊。
- 标题能选 1P/2P；有战斗画面与 HUD 占位。
- 键盘能产生 input 对象。
- 不修改 t001、t003 文件。

## 验证方式

- 启动前端目视缩放与标题。
- 前端 `tsc` 通过。
